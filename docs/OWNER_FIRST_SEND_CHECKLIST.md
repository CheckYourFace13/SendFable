# Owner first-send activation checklist

Use a real mailbox you control. Do not email prospects.

- [ ] Signup at https://sendfable.com/signup
- [ ] Verify email from inbox
- [ ] Complete onboarding (business → sender → contacts → create)
- [ ] Confirm mailing address in settings
- [ ] Verify sender identity
- [ ] Add 3 synthetic contacts (your aliases)
- [ ] Create campaign from template or blank
- [ ] Send Confidence shows ready (fix blockers if any)
- [ ] Send to the 3 contacts only
- [ ] Confirm From / Reply-To / subject / footer address / unsubscribe
- [ ] Confirm Free badge “Sent with SendFable” if on Free
- [ ] Click a link; confirm tracking redirect
- [ ] Unsubscribe one contact; confirm suppressed
- [ ] Duplicate campaign; save second draft
- [ ] Optional: start Starter checkout and abandon (confirm Stripe URL) — do not charge unless intended

When complete, note date + any friction in `/admin/funnel` event gaps.
